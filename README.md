# DoomSI 😈

A tiny Chrome extension that makes browsing a little more fun.

DoomSI randomly swaps selected images on web pages with your own collection. Perfect for harmless chaos, inside jokes, memes, or making every website look like it was designed by your team.

## Features

* Replace images on any website
* Add your own custom images
* Lightweight and simple
* No accounts, no tracking, no nonsense

## Installation

1. Clone this repo
2. Open `chrome://extensions`
3. Enable **Developer Mode**
4. Click **Load unpacked**
5. Select the project folder
